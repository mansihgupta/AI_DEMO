AWS Bedrock Agent Security POC

GitHub Repository Implementation Guide

This document identifies the recommended GitHub repositories, how they align with the planned architecture, and the recommended implementation sequence for building a secure Bedrock AgentCore Proof of Concept using PingFederate, Cedar Authorization, Bedrock Agents, Lambda Tools, and Least Privilege IAM controls.

POC Goal

Validate an end-to-end security architecture supporting:

  • PingFederate Authentication
  • OIDC Identity Federation
  • Temporal Session Controls
  • Cedar Fine-Grained Authorization
  • Amazon Bedrock Agent Runtime
  • Lambda Action Groups
  • Last Mile Authorization
  • Least Privilege Session Policies

Repository #3 (Authorization Layer)

Cedar Policy Language

https://github.com/cedar-policy/cedar

Purpose

Provides the official Cedar authorization engine and policy language.

Use Cases

  • Tool Authorization
  • Department Authorization
  • Resource Access Authorization
  • ABAC Controls
  • RBAC Controls

Example Policy

permit(
    principal,
    action == Action::"ExecuteTool",
    resource == Resource::"FinanceDatabase"
)
when {
    principal.department == "Finance"
};

Authorization Flow

User Claims
      |
      v
Cedar Evaluation
      |
      +--> Deny

      +--> Allow
                |
                v
          Bedrock Agent

Benefits

  • Blocks unauthorized actions before LLM execution
  • Reduces token consumption costs
  • Provides auditable authorization decisions
